package router // import "github.com/faustbrian/go-router/v2"

Package router compiles explicit route descriptors into immutable net/http
handlers. Start with New, register routes or groups, then Compile; the builder
is single-owner, while the compiled indexes support concurrent dispatch,
introspection and named URL generation. Handler and middleware synchronization,
cancellation, panics and lifecycle remain the application's responsibility.

Matching uses ServeMux's literal and wildcard grammar. Redirect serialization
deliberately retains Go 1.26.6 behavior; HTTP method and URI-generation choices
are recorded in docs/specification-decisions.md. This standard-library-only
package starts no servers or goroutines and supplies no authentication, proxy
trust, service discovery or cgo dependency.

TYPES

type BaseURL struct {
	// Has unexported fields.
}
    BaseURL is an immutable absolute-URL origin constructed by NewBaseURL. Its
    zero value is invalid for URL. Validation is syntactic, not a decision that
    the origin is authorized or reachable; the caller owns that trust policy.

func NewBaseURL(scheme, authority string) (BaseURL, error)
    NewBaseURL validates one caller-trusted HTTP or HTTPS scheme and authority.
    It lowercases the scheme and accepts bounded ASCII authorities without
    userinfo, URL paths, controls or malformed ports. Authority spelling is
    retained; DNS resolution, IDNA conversion and proxy trust are not performed.
    Invalid syntax returns ErrGeneration; fixed byte ceilings return
    ErrLimitExceeded.

type Builder struct {
	// Has unexported fields.
}
    Builder owns mutable startup-time registration state and is not safe for
    concurrent use. Construct it with New; its zero value has no valid budgets.
    A successful Compile freezes registration, groups, mounts and recompilation.
    Failed compilation leaves descriptors retained but publishes no Router;
    rebuilding is necessary to remove or replace a conflicting descriptor.

func New(options ...Option) *Builder
    New creates an empty single-owner builder with DefaultLimits, automatic
    OPTIONS enabled and FollowRedirects. It always returns a builder: nil
    options and invalid built-in settings are deferred errors, not constructor
    panics. Custom option panics propagate.

func (b *Builder) Compile() (*Router, error)
    Compile validates the complete route set and returns an immutable router,
    freezing this builder only on success. Nil/frozen builders, conflicts,
    duplicate names, invalid middleware and excess budgets return typed Error
    categories with no partial Router. Pattern conflicts are checked before
    any middleware constructor runs, but a later constructor failure can leave
    earlier callback side effects; those effects and all callback panics are
    caller-owned.

func (b *Builder) Group(options GroupOptions, define func(*Builder) error) error
    Group transactionally flattens routes registered by define. If group-option
    validation or define returns an error, no group route is published to the
    parent. define must propagate failed child registrations; ignored errors do
    not abort it. define runs synchronously on a child builder; do not mutate
    the parent from inside it or retain the child for later registration.
    On normal callback return the child is frozen, even after an error. Callback
    panics/effects are not recovered or rolled back. Route-set conflicts remain
    Compile's responsibility.

func (b *Builder) Mount(prefix string, handler http.Handler, options MountOptions) error
    Mount registers handler below an explicit path boundary. The mount is one
    ordinary remainder-wildcard route and therefore follows the active redirect
    policy for a request missing the boundary's trailing slash. prefix must be
    a non-empty absolute literal prefix; no implicit authentication or resource
    lifecycle is added. Registration copies options' slices/maps, not handler
    state. StripPrefix changes only the mounted request view; nested routers
    preserve outer path values unless an inner wildcard reuses the name.

func (b *Builder) PendingRoutes() []Route
    PendingRoutes returns independent collection copies in registration order,
    including after successful compilation. Handlers and middleware functions
    remain shared caller-owned values. A nil builder returns nil.

func (b *Builder) Register(route Route) error
    Register validates, flattens and copies one route descriptor without
    invoking its handler or middleware. It rejects malformed or unsupported
    input, excess budgets and frozen/nil builders with typed Error categories.
    Cross-route conflicts and resolved middleware are checked by Compile.
    Successful routes cannot subsequently be removed; copying collections does
    not copy callbacks.

type Error struct {
	// Kind is the underlying category returned by Unwrap; nil has no category.
	Kind error
	// Field identifies the rejected input dimension; empty omits it from text.
	Field string
	// Source is an optional caller-owned diagnostic label, not a filesystem read.
	// Keep it non-sensitive; rendered text truncates it independently.
	Source string
	// Detail describes the refusal. Error bounds and sanitizes its rendered form.
	Detail string
}
    Error is a startup or generation diagnostic. Kind supports errors.Is;
    callers may use errors.As to inspect its unsanitized fields. Error sanitizes
    controls and bounds rendered text, but does not redact caller-provided
    secrets. Treat source labels and custom Kind values as disclosure-bearing
    inputs. A zero Error and a nil *Error both render as "router error".

func (e *Error) Error() string
    Error returns single-line valid UTF-8 bounded to 160 bytes, including
    any caller-supplied source label. It replaces controls and truncates,
    not redacts.

func (e *Error) Unwrap() error
    Unwrap exposes the stable error category.

type GroupOptions struct {
	// Host supplies the group hostname pattern. Non-empty nested/route hosts
	// must match case-insensitively; empty inherits the outer host.
	Host string
	// PathPrefix joins literally to descendant paths. Empty or / adds no prefix;
	// other values must be absolute literals without wildcards, dot segments,
	// encoded separators, query/fragment syntax or repeated slashes.
	PathPrefix string
	// NamePrefix concatenates literally with descendant names without adding
	// a separator; empty leaves them unchanged. The composed name is bounded.
	NamePrefix string
	// Middleware adds inherited layers in outer-to-inner request order. Slices
	// are copied; callbacks are retained and excluded only with owner permission.
	Middleware []NamedMiddleware
	// Metadata is copied and merged with descendants. Any repeated key is a
	// conflict, even when the value agrees; values must satisfy the final budgets.
	Metadata map[string]string
}
    GroupOptions composes a host, path and name prefix, middleware, and metadata
    into every route registered by a group callback.

type Limits struct {
	// MaxRoutes caps retained flattened descriptors, counting each mount once.
	MaxRoutes int
	// MaxGroups caps successful group callbacks, including empty/nested groups.
	MaxGroups int
	// MaxGroupDepth caps nested child-builder depth.
	MaxGroupDepth int
	// MaxMethodsPerRoute caps explicitly registered methods per descriptor.
	MaxMethodsPerRoute int
	// MaxMethodBytes caps each registered or dispatched method token in bytes.
	MaxMethodBytes int
	// MaxWildcardsPerRoute caps combined host/path wildcard occurrences; the
	// path count also includes the {$} end marker.
	MaxWildcardsPerRoute int
	// MaxWildcardNameBytes caps each wildcard/generation parameter name.
	MaxWildcardNameBytes int
	// MaxPatternBytes caps paths, composed group prefixes and mount patterns.
	MaxPatternBytes int
	// MaxHostBytes caps registered route/group host patterns, not trusted bases.
	MaxHostBytes int
	// MaxNameBytes caps route/group names, middleware names and exclusions.
	MaxNameBytes int
	// MaxSourceBytes caps registered source labels before retention.
	MaxSourceBytes int
	// MaxOperationBytes caps retained operation identifiers.
	MaxOperationBytes int
	// MaxDocumentationBytes caps retained descriptive route text.
	MaxDocumentationBytes int
	// MaxMetadataEntries caps composed metadata entry counts before merging.
	MaxMetadataEntries int
	// MaxMetadataKeyBytes caps each non-empty metadata key.
	MaxMetadataKeyBytes int
	// MaxMetadataValueBytes caps each metadata value; empty values are valid.
	MaxMetadataValueBytes int
	// MaxMiddleware caps middleware collections, exclusions and resolved depth.
	MaxMiddleware int
	// MaxRequestTargetBytes caps RequestURI, decoded/raw/escaped path and raw
	// query components plus escaped-path/query bytes; excess dispatch returns 414.
	MaxRequestTargetBytes int
	// MaxURLParameters caps compiled wildcard names, generation descriptors and
	// total supplied segment values, including remainder segments.
	MaxURLParameters int
	// MaxURLParameterBytes caps cumulative raw parameter-name and value bytes.
	MaxURLParameterBytes int
	// MaxQueryValues caps query key count and total entries; an empty value list
	// consumes one entry even though encoding emits no pair.
	MaxQueryValues int
	// MaxQueryBytes caps cumulative raw query key/value bytes before encoding.
	MaxQueryBytes int
	// MaxGeneratedURLBytes caps final escaped relative/absolute output bytes.
	MaxGeneratedURLBytes int
}
    Limits bounds construction, dispatch and URL-generation inputs.
    Every field must be positive; start with DefaultLimits and adjust trusted
    startup budgets. WithLimits validates positivity but imposes no ceiling
    on caller-selected maxima. Limits are retained by value and do not bound
    callback execution. Byte budgets count bytes, not runes; limits reject
    rather than truncate input.

func DefaultLimits() Limits
    DefaultLimits returns conservative production budgets.

type Middleware = func(http.Handler) http.Handler
    Middleware is the standard HTTP decorator shape. Construction happens
    during Compile, in reverse request order. Constructors must return a non-nil
    handler; callbacks own blocking, cancellation, re-entry, shared-state
    synchronization, partial responses and panics. The router adds no recovery
    or writer wrapper.

type MiddlewareExclusionPolicy uint8
    MiddlewareExclusionPolicy controls whether a route may remove an inherited
    middleware layer. The zero value denies exclusion so security-sensitive
    middleware remains enforced unless its owner explicitly opts out.

const (
	// MiddlewareExclusionDenied keeps inherited middleware non-excludable.
	MiddlewareExclusionDenied MiddlewareExclusionPolicy = iota
	// MiddlewareExclusionAllowed permits a route to exclude a named inherited layer.
	MiddlewareExclusionAllowed
)
type MountOptions struct {
	// Name is the optional stable name of the single generated remainder route.
	Name string
	// Methods selects explicit uppercase HTTP methods. Empty defaults to DELETE,
	// GET, HEAD, OPTIONS, PATCH, POST and PUT; TRACE requires explicit inclusion.
	Methods []string
	// Host limits the mount to a Route.Host pattern; empty inherits group policy.
	Host string
	// Middleware appends mount-local layers after router/group middleware.
	Middleware []NamedMiddleware
	// Metadata supplies copied bounded route data with no inherited key overrides.
	Metadata map[string]string
	// Documentation is optional bounded text exposed in RouteInfo.
	Documentation string
	// Operation is an optional bounded identifier exposed in RouteInfo.
	Operation string
	// Source is an optional bounded diagnostic label, not redacted secret data.
	Source string
	// StripPrefix gives the handler a cloned request and URL with the decoded
	// prefix removed and escaped suffix preserved. RequestURI remains original.
	// False leaves the selected request URL view unchanged.
	StripPrefix bool
}
    MountOptions configures an explicit standard-handler mount.

type NamedMiddleware struct {
	// Name identifies this layer for introspection and inherited exclusions.
	// Empty permits unnamed layers and skips name-based duplicate detection.
	Name string
	// Middleware constructs a non-nil handler at compile time. The function
	// and returned handler remain caller-owned and must support intended reuse.
	Middleware Middleware
	// ExclusionPolicy controls whether routes may remove this inherited layer.
	// The zero value denies removal; route-local middleware is never excluded.
	ExclusionPolicy MiddlewareExclusionPolicy
}
    NamedMiddleware makes a middleware layer visible through introspection.
    Name may be empty when exclusion and duplicate detection are not needed.
    ExclusionPolicy defaults to MiddlewareExclusionDenied.

type Option func(*Builder)
    Option configures a Builder synchronously during New. Options run in order;
    built-in validation errors are retained for Register, Group, Mount or
    Compile. Custom options own their effects and panics and must not retain the
    builder for concurrent mutation.

func WithAutomaticOPTIONS(enabled bool) Option
    WithAutomaticOPTIONS controls package-generated OPTIONS responses,
    enabled by default. Explicit OPTIONS routes win. Automation emits 204 with
    sorted Allow for matching paths or OPTIONS *; disabling it sends OPTIONS *
    to not-found.

func WithLimits(limits Limits) Option
    WithLimits replaces all construction, dispatch and generation limits. Every
    field must be positive; positivity does not cap caller-selected maxima.
    An invalid value is retained as ErrLimitExceeded for subsequent operations.

func WithMethodNotAllowed(handler http.Handler) Option
    WithMethodNotAllowed replaces the minimal default 405 handler. The router
    sets Allow before invoking it. Nil, including a typed nil, becomes a
    deferred ErrInvalidRoute. It runs outside route middleware and owns its
    response, blocking, cancellation and panics; malformed requests bypass it.

func WithMiddleware(middleware ...NamedMiddleware) Option
    WithMiddleware replaces router-wide middleware in request execution order.
    New copies the final slice after applying all options, not the callback
    state. Middleware constructors run during Compile; invalid names, duplicate
    resolved names and nil functions/returned handlers prevent successful
    publication.

func WithNotFound(handler http.Handler) Option
    WithNotFound replaces the default 404 handler. Nil, including a typed nil,
    becomes a deferred ErrInvalidRoute. This handler runs outside route
    middleware and owns its response, blocking, cancellation and panics;
    malformed requests bypass it.

func WithRedirectPolicy(policy RedirectPolicy) Option
    WithRedirectPolicy selects explicit canonical-path redirect behavior.

type RedirectPolicy uint8
    RedirectPolicy controls ServeMux canonical-path and subtree redirects.

const (
	// FollowRedirects retains the pinned Go 1.26.6 canonical/subtree redirect form.
	FollowRedirects RedirectPolicy = iota
	// RejectRedirects treats a match requiring canonicalization as not found.
	RejectRedirects
)
type Route struct {
	// Name is an optional stable generation/introspection name. Non-empty names
	// must be unique across the compiled table, including group prefixes.
	Name string
	// Methods is a non-empty set of distinct uppercase HTTP tokens. GET also
	// serves HEAD unless an explicit HEAD pattern wins; CONNECT is unsupported.
	Methods []string
	// Host is an optional ASCII hostname pattern without a port. Empty matches
	// any host; {name} captures exactly one label. IDNA conversion is caller-owned.
	Host string
	// Path is an absolute ServeMux literal/wildcard pattern, including {name},
	// {name...} and {$}. Invalid escapes and decoded dot segments are rejected.
	Path string
	// Handler serves the selected route and must not be nil or typed nil.
	// The router neither closes it nor recovers its panics or owns its state.
	Handler http.Handler
	// Middleware appends route-local layers after router and group layers.
	// Constructor and serving effects remain caller-owned.
	Middleware []NamedMiddleware
	// ExcludeMiddleware names inherited layers to remove only when each owner
	// allows exclusion. It never removes route-local layers; unknown names are
	// ignored, but empty, malformed or duplicate names fail compilation.
	ExcludeMiddleware []string
	// Metadata is copied descriptive data, not authorization state. Keys must
	// be non-empty, bounded and disjoint from inherited group metadata.
	Metadata map[string]string
	// Documentation is optional bounded introspection text, not executable policy.
	Documentation string
	// Operation is an optional bounded introspection identifier, not dispatch logic.
	Operation string
	// Source is an optional bounded caller label included in startup diagnostics.
	// It is not redacted; avoid secrets and personal data.
	Source string
}
    Route is an explicit route descriptor. Builder.Register copies every slice
    and map before retaining it.

type RouteInfo struct {
	// Name is the optional stable route name after group composition.
	Name string
	// Methods contains sorted explicitly registered methods, not implied HEAD
	// or automatic OPTIONS additions.
	Methods []string
	// Host is the registered composed host pattern, not the request authority.
	Host string
	// Pattern is the composed path pattern, not the concrete requested path.
	Pattern string
	// Parameters lists host wildcards left-to-right, then path wildcards in
	// pattern order, with no duplicate names.
	Parameters []string
	// Middleware lists resolved layers in request order; unnamed layers appear
	// as empty strings, and excluded inherited layers are omitted.
	Middleware []string
	// Metadata is a copied descriptive map with the composed route entries.
	Metadata map[string]string
	// Documentation is the retained bounded descriptive text.
	Documentation string
	// Operation is the retained optional identifier, not handler identity.
	Operation string
	// Source is the retained caller diagnostic label; it is not redacted.
	Source string
}
    RouteInfo is a defensive snapshot of a compiled route, omitting handlers
    and function identity. Its exported fields are mutable caller-owned data:
    changing them does not change dispatch. Methods, Parameters, Middleware and
    Metadata are independently copied whenever information crosses the API.

func MatchedRoute(request *http.Request) (RouteInfo, bool)
    MatchedRoute returns the route selected for request, when called from its
    handler or middleware chain. It returns a defensive snapshot, or zero/false
    for nil requests or absent package route context. Nested routers install
    their own matched metadata; this function reports the context on the
    supplied view.

type Router struct {
	// Has unexported fields.
}
    Router has immutable compiled indexes supporting concurrent ServeHTTP,
    Routes, Path and URL calls. Construct it through Builder.Compile; its zero
    value has no initialized routing budgets. Retained handlers/middleware must
    provide their own concurrency safety and resource lifetime. Router starts no
    goroutines, does no background I/O and has no Close operation.

func (r *Router) Path(name string, parameters ...URLParameter) (string, error)
    Path generates a relative escaped path for a named route. Host
    wildcard values are intentionally not accepted by relative generation.
    Supply each path wildcard exactly once with the appropriate Param or
    Remainder kind; unknown, duplicate, missing, unused or unsafe values return
    ErrInvalidParameter. Names absent from the table return ErrGeneration, nil
    routers return ErrCompileState and budget excess returns ErrLimitExceeded.
    Failures return an empty string. Segments are escaped once with
    url.PathEscape (RFC 3986 sections 2.1/3.3; ROUTER-DEC-011), including
    literal percent and separator bytes as data.

func (r *Router) Routes() []RouteInfo
    Routes returns independent snapshots sorted by name, host, path and method
    set, with methods sorted within each entry. It copies the full table and
    nested collections, so cost is linear in the published data. A nil Router
    returns nil; a compiled empty router returns a non-nil empty slice.

func (r *Router) ServeHTTP(writer http.ResponseWriter, request *http.Request)
    ServeHTTP dispatches synchronously without mutating compiled state. It
    rejects nil router/request/URL, invalid authorities/methods and CONNECT with
    400, and excess targets with 414, before route middleware or custom miss
    handlers. It follows RedirectPolicy, explicit routes, automatic OPTIONS,
    known-path 405, unsupported-method 501 and ordinary 404 in that order.

    Handlers receive standard PathValue entries and matched metadata on a
    derived context. URL and RequestURI remain unchanged except for a mounted
    handler's optional cloned URL view; ServeMux owns its ordinary request
    path-value state. Supply a non-nil writer. The router does not recover
    panics, wrap the writer, stop canceled requests automatically or constrain
    caller callback execution.

func (r *Router) URL(name string, base BaseURL, query url.Values, parameters ...URLParameter) (string, error)
    URL generates an absolute URL using a validated explicit base. A route
    host replaces the base hostname while retaining its trusted explicit port.
    No request or forwarding header supplies authority. Parameters obey Path's
    error rules and additionally require every host wildcard; a zero base or
    unknown name returns ErrGeneration. Nil query is accepted. Query keys are
    sorted by url.Values.Encode, values retain supplied order, and the query
    is not mutated; callers must not mutate its maps/slices concurrently.
    Empty value lists count toward admission budgets but emit nothing. Failures
    return an empty string.

type URLParameter struct {
	// Has unexported fields.
}
    URLParameter is an explicitly typed named-route generation input. Construct
    values with Param or Remainder. The zero value is invalid during generation;
    values are reusable because constructors retain strings or copy segment
    slices and generation never mutates them.

func Param(name, value string) URLParameter
    Param supplies one path segment or host label. It defers name/value
    validation to Path or URL. Path separators inside an otherwise valid segment
    are escaped as data, not expanded into remainder segments.

func Remainder(name string, segments ...string) URLParameter
    Remainder supplies explicit path segments for a remainder wildcard. Inputs
    above the package hard ceiling are rejected during generation without being
    copied. Smaller slices are defensively copied; strings remain immutable.
    Generation requires at least one segment, rejects empty/dot/slash-only
    segments and NUL/CR/LF, and still applies the router's lower parameter and
    byte budgets.

package routertest // import "github.com/faustbrian/go-router/v2/routertest"

Package routertest provides small consumer-facing helpers for compiled route
tests without introducing a parallel runtime API. Start with MustCompile and
Serve using a testing.TB-compatible value. Helpers invoke handlers synchronously
in memory, start no server, add no deadline or panic recovery and do not own
application resources; blocking and cancellation remain handler/caller policy.

FUNCTIONS

func AssertStatus(testingT TestingT, response *httptest.ResponseRecorder, expected int)
    AssertStatus fails the test for a nil response or unexpected recorded code;
    a nil response is reported as actual status zero.

func MustCompile(testingT TestingT, builder *router.Builder) *router.Router
    MustCompile compiles builder once or fails the test, returning nil if Fatalf
    returns. A nil builder is reported through its typed compile-state error;
    constructors' panics still propagate and successful compilation freezes it.

func RouteTable(testingT TestingT, compiled *router.Router) []router.RouteInfo
    RouteTable returns a copied compiled route table or fails for a nil router.

func Serve(testingT TestingT, handler http.Handler, method, target string) *httptest.ResponseRecorder
    Serve synchronously sends a bodyless request with context.Background to
    handler and returns its recorder. Invalid method/target fails the test and
    returns nil if Fatalf returns. handler must be non-nil and owns blocking and
    panics; construct your own request when testing cancellation or deadlines.


TYPES

type TestingT interface {
	// Helper marks the caller as test support for failure locations.
	Helper()
	// Fatalf reports the formatted failure and normally ends the test goroutine.
	Fatalf(format string, arguments ...any)
}
    TestingT is the subset of testing.TB used by the helpers. It must be
    non-nil; real testing.TB values end the current test goroutine on Fatalf.
    Helpers return defensively after reporting failure even if a test double's
    Fatalf returns.
